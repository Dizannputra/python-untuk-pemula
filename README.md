# Belajar Python untuk Pemula

Repository ini berisi kuis, modul, dan latihan praktikum dasar pemrograman Python yang dipelajari dalam materi "Python untuk Pemula".

---

## 📌 Rangkuman Materi
Materi yang dipelajari dalam repository ini meliputi:
- **Variabel & Tipe Data**: Penggunaan tipe data dasar seperti String, Integer, Float, dan Boolean.
- **Pengkondisian (If/Else)**: Alur logika untuk mengambil keputusan berdasarkan kondisi tertentu.
- **Perulangan (Loops)**: Mengulangi eksekusi blok kode dengan `for` dan `while`.
- **Manajemen Package & Environment**: Membuat *virtual environment* (`venv`) dan mengelola dependensi modul menggunakan `pip`.

---
